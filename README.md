# Wandr marketing website

Next.js App Router marketing funnel for Wandr.

```bash
bun install
bun run dev
```

The production build is static-friendly and can be deployed to Vercel with the default Next.js settings:

```bash
bun run build
```

All download CTAs point to the Wandr App Store listing. Legal pages are available at `/privacy` and `/terms`.

The showcase image is “Summer landscape in mountains,” a public-domain U.S. Fish & Wildlife Service image sourced through Wikimedia Commons.
